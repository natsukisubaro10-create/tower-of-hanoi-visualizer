TOWER OF HANOI — PROLOG VISUALIZER

Requirements:
- SWI-Prolog installed: https://www.swi-prolog.org/

Run:
1. Extract this folder.
2. Open a terminal/Command Prompt in the extracted folder.
3. Run: swipl -q -s hanoi.pl
4. Open http://localhost:8000 in your browser.
5. Select 1–8 disks and press Start.

The Prolog server computes the move list. The HTML/CSS/JavaScript frontend animates the moves.
Stop the server with Ctrl+C in the terminal.
